# Silent-Speech

Set up instructions

First you will need to create a conda env with at least Python 3.8

> conda create -n bci_env python=3.8
> conda activate bci_env

Next, install dependencies

> cd synthesis
>
> pip install -r requirements.txt  
> pip install -U pip setuptools   
> pip install -e .

Please install the GSLM library from source  
> https://github.com/facebookresearch/fairseq

Install all the pretrained models  

> Waveglow [https://dl.fbaipublicfiles.com/textless_nlp/gslm/waveglow_256channels_new.pt](https://dl.fbaipublicfiles.com/textless_nlp/gslm/waveglow_256channels_new.pt)   
> TTS [https://dl.fbaipublicfiles.com/textless_nlp/gslm/hubert/tts_km100/tts_checkpoint_best.pt](https://dl.fbaipublicfiles.com/textless_nlp/gslm/hubert/tts_km100/tts_checkpoint_best.pt)    
> Hubert [ https://dl.fbaipublicfiles.com/hubert/hubert_base_ls960.pt]( https://dl.fbaipublicfiles.com/hubert/hubert_base_ls960.pt)  
> Code Dict [https://dl.fbaipublicfiles.com/textless_nlp/gslm/hubert/tts_km100/code_dict](https://dl.fbaipublicfiles.com/textless_nlp/gslm/hubert/tts_km100/code_dict)  


The EMG and audio data can be downloaded from [https://doi.org/10.5281/zenodo.4064408](https://doi.org/10.5281/zenodo.4064408) The scripts expect the data to be located in a emg_data subdirectory by default, but the location can be overridden with flags (see the top of read_emg.py).

To install required packages  
> pip install librosa soundfile jiwer unidecode deepspeech==0.8.2  
> pip install praat-textgrids  
> pip install absl-py  


Download pre-trained DeepSpeech model files for vocoding.  
> curl -LO https://github.com/mozilla/DeepSpeech/releases/download/v0.7.0/deepspeech-0.7.0-models.pbmm  
> curl -LO https://github.com/mozilla/DeepSpeech/releases/download/v0.7.0/deepspeech-0.7.0-models.scorer


To run the training loop use the below command  
> python3 training.py --model_type "Model" --experiment_name "ssi" --run_name "1" --config "example_config.yaml" --root_dir /


Code files in this repository are taken from [https://github.com/UCSF-Chang-Lab-BRAVO/multimodal-decoding](https://github.com/UCSF-Chang-Lab-BRAVO/multimodal-decoding) and [https://github.com/dgaddy/silent_speech](https://github.com/dgaddy/silent_speech). These files are tweaked according to our need.
